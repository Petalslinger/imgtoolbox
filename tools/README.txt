这个目录可以整个删掉。

原本打算在这里放一个 node 脚本，生成一个内嵌全部源码的自检页，
好在浏览器里做语法检查。但本机沙箱不允许执行 node，脚本的产出没人
验证，属于自己骗自己，所以放弃了那条路。

现在的自检在项目根目录的 selftest.html：纯静态、不需要任何生成步骤。
它直接加载 js/ 下的真实模块，然后真跑：

  一、模块是否全部加载
  二、每个 js 文件的语法（fetch 源码 + new Function 编译，不执行）
  三、排序与文件名（数字感知排序、扩展名拆分、补零）
  四、重命名规则引擎（替换 / 正则 / 前后缀 / 编号 / 重名检测）
  五、缩放数学（等比、禁止放大、多步链式）
  六、DEFLATE 往返
  七、图片字节解析（用 canvas 真编出来的 PNG / JPEG 验 IHDR 与 SOF 偏移）
  八、PDF 结构与严格校验（pdfLint 走完整 xref、按 /Length 定位流、打印十六进制）
  八·四、交给 pdf.js（Firefox 的 PDF 引擎）实际解析，做独立实现交叉验证
  九、ZIP 结构（签名、中央目录偏移、UTF-8 文件名标志位、deflate 往返）
  十、带 alpha 的 PNG 垫白底后写入 PDF
  十一、端到端（改分辨率分区与导出 PDF 分区各跑一遍，验证互不干扰）

双击 selftest.html 就能看结果。
